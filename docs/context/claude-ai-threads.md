# Curated Claude.ai threads

Anthropic does not expose an API to import Claude.ai chat history. Paste curated excerpts here manually so future Claude Code sessions have the same long-term memory you do.

## How to use this file
- One section per thread. Most recent first.
- Keep only the **decisions** and **gotchas** — not the back-and-forth.
- Link the original thread URL if you can.
- When a section gets stale or contradicts a newer one, delete it.

## Format
```
## YYYY-MM-DD — <short title>
**Source:** <Claude.ai thread URL or "memory">
**Topic:** <one-line>

- Decision: ...
- Why: ...
- Gotcha / counterexample: ...
- Follow-up: ...
```
